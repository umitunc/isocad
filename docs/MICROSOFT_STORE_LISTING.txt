2. ENGLISH (en-US) — STORE LISTING

[Title / App Name]
IsoCad

[Short Title / Subtitle]
WebGL2 CAD & Industrial Piping Isometric PDF Editor

[Short Description (Özet Açıklama)]
High-performance 60 FPS WebGL2 CAD drafting and industrial Piping Isometric PDF editor with automated MTO, Weld Log, Cut List extraction, As-Built weldmap stamping, lossless vector PDF/Excel/DXF export, and REST/Webhook API sync.

[Full Description (Detaylı Açıklama)]
IsoCad is a high-performance desktop and browser-native CAD & Industrial Piping Isometric PDF Intelligence platform built for piping engineers, QA/QC teams, fabricators, and EPC contractors.

Powered by a custom 60 FPS WebGL2 instanced vector engine and an AutoCAD-compatible command workflow, IsoCad eliminates heavy legacy CAD installations while delivering precision isometric drafting, automated engineering table extraction, and lossless vector PDF output.

KEY CAPABILITIES:
• 60 FPS WebGL2 Vector CAD Engine: Hardware-accelerated instanced rendering with R-Tree spatial indexing (OSNAP), F5 Isometric Plane locking (30° / 90° / 150°), Ortho/Polar tracking, and familiar CAD commands.
• Automated Piping Isometric Extraction: Automatically parses Material Take-Off (MTO), Cut Pipe Length lists, Support Lists, and Weld Logs from Danieli Standard, Danieli Russian Cyrillic, Linde/Energiron, and stamped As-Built isometric PDFs.
• As-Built Weld & Welder Stamping: Dual-compartment Weld & Welder inspection stamps with smart edge-snapping leader lines, weld topology validation, and instant tabular synchronization.
• Lossless Multi-Format Export: Export crisp lossless vector PDFs (preserving original engineering drawings), structured 5-sheet Excel workbooks (.xlsx), JSON data envelopes, and AutoCAD-compatible DXF files.
• Bidirectional API & ERP/MES Integration: Built-in REST Webhook adapter (POST/PUT JSON + Vector PDF), Stellar API integration, and embeddable bridge support for seamless enterprise workflows.
• 100% Offline Desktop Ready: All core CAD rendering, PDF parsing, and export engines run locally on your machine with no internet connection required.

MULTILINGUAL & THEME SUPPORT:
• Interface available in English, Turkish, and Russian.
• Dark & Light themes designed for long engineering sessions.

[Product Features (Özellik Maddeleri - Store Listelemesi İçin)]
1. 60 FPS WebGL2 CAD engine with R-Tree OSNAP and F5 Isoplane (30°/90°/150°)
2. Automated MTO, Weld Log, Cut List & Support extraction from Piping Isometric PDFs
3. Danieli (EN/RU) & Linde/Energiron isometric PDF format support
4. As-Built dual-compartment Weld & Welder stamping with edge-snapping leaders
5. Lossless Vector PDF, 5-sheet Excel (.xlsx), JSON & DXF export
6. Bidirectional REST/Webhook & ERP/MES API synchronization
7. Full offline Windows desktop execution with local file persistence

WebGL2 CAD & Endüstriyel Piping İzometrik PDF Düzenleyici

[Detaylı Açıklama (Full Description)]
IsoCad; borulama (piping) mühendisleri, kalite kontrol (QA/QC) ekipleri, imalat atölyeleri ve EPC yüklenicileri için geliştirilmiş yüksek performanslı bir WebGL2 CAD ve Endüstriyel Piping İzometrik PDF düzenleme platformudur.

Özel 60 FPS WebGL2 vektör motoru ve AutoCAD uyumlu komut akışı sayesinde ağır masaüstü CAD kurulumlarına gerek kalmadan hassas izometrik çizim, otomatik mühendislik tablosu çıkarımı ve kayıpsız vektörel PDF çıktısı üretir.

ÖNE ÇIKAN ÖZELLİKLER:
• 60 FPS WebGL2 Vektör CAD Motoru: Donanım hızlandırmalı çizim, R-Tree uzamsal indeksleme (OSNAP), F5 İzometrik Düzlem kilidi (30° / 90° / 150°), Ortho/Polar yakalama ve tanıdık CAD komut satırı.
• Otomatik Piping İzometrik Veri Çıkarımı: Danieli Standart, Danieli Kiril (Rusça), Linde/Energiron ve damgalı As-Built izometrik PDF'lerden Malzeme Listesi (MTO), Boru Kesim Listesi (Cut List), Destek Listesi (Support List) ve Kaynak Listesini (Weld Log) otomatik olarak ayrıştırır.
• As-Built Kaynak & Kaynakçı Damgalama: Çift bölmeli kaynak ve kaynakçı damgaları, kenara yapışan akıllı lider çizgileri (leader lines), kaynak topoloji doğrulaması ve anlık tablo senkronizasyonu.
• Kayıpsız Çoklu Format Dışa Aktarım: Orijinal teknik çizimi bozmayan kayıpsız vektörel PDF, 5 sekmeli yapılandırılmış Excel (.xlsx) çalışma kitabı, JSON veri paketi ve AutoCAD uyumlu DXF çıktısı.
• Çift Yönlü API & ERP/MES Entegrasyonu: REST Webhook adaptörü (POST/PUT JSON + Vektörel PDF) ve kurumsal sistemlerle çift yönlü veri senkronizasyonu.
• Tam Çevrimdışı Masaüstü Çalışma: Tüm CAD motoru, PDF ayrıştırma ve dışa aktarım araçları internet bağlantısı olmadan yerel olarak çalışır.
